# Admonitions

This file is used to test the rendering and display of GitHub style admonitions. These are the five types as supported by GitHub ([see source](https://github.com/orgs/community/discussions/16925)).

> [!NOTE]  
> Highlights information that users should take into account, even when skimming. This is some more text because I wish to know how well or badly this here goes with all the indents.
> 
> This also has a **second** paragraph to try things out.

> [!TIP]
> Optional information to help a user be more successful.

> [!IMPORTANT]  
> Crucial information necessary for users to succeed.

> [!WARNING]  
> Critical content demanding immediate user attention due to potential risks.

> [!CAUTION]
> Negative potential consequences of an action.

Now to Obsidian style callouts, which can have a custom title:

> [!caution] Custom "Caution" title
> This is a caution with a custom title.

Finally, a nested admonition:

> [!note]
> A note with a nested admonition.
> 
> > [!tip]
> > Nesting admonitions is also possible.
> 
> Back at the note level.
